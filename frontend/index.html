    CONCEPT NOTES

    What this visualization does — and does not — say

    ↗

    Comoving coordinates

    The markers represent idealized comoving locations. Their displayed separation scales with a, while the drawing omits local gravitationally bound systems.

    ◷

    Redshift

    Cosmological redshift is related to expansion between emission and observation. This slider uses the simple relation a = 1/(1+z).

    ⚑

    Model boundaries

    Expansion history requires a cosmological model and parameters. The canvas is an explanatory animation, not a computed solution to the Friedmann equations.

    CONCEPT GUIDE

    What does the CMB show?

    01
    Relic radiation

    The CMB is light released when the early universe became transparent.

    02
    Anisotropies

    Small temperature variations encode information about early density perturbations and cosmological parameters.

    03
    Interpretation matters

    Real analyses require calibrated maps, masks, beams, foreground treatment, and an angular power-spectrum estimator.

    ◉

    All-sky projection

    An oval projection can display a full-sky map on a flat page, but it distorts angular geometry. Scientific analyses often use HEALPix pixelization.

    ∿

    Angular scales

    Patterns on different angular scales contribute to the angular power spectrum. This generated map is not drawn from a measured or fitted spectrum.

    ⚑

    Data provenance

    Do not cite or export this visual as an observation. It is a frontend texture for explaining interface controls and high-level ideas.

    READ THE SCENE

    Visual guide

    01
    Source position

    Faint markers show approximate background-source coordinates before applying the lens mapping.

    02
    Apparent images

    Bright markers move as the toy Einstein-angle scale changes, giving a visual sense of image displacement.

    03
    Mass profile matters

    Real lens systems require a mass model, geometry, and often a numerical lens equation solver.

    ↝

    Deflection of light

    In general relativity, mass-energy curves spacetime and changes the paths along which light propagates.

    ◎

    Einstein angle

    The characteristic angular scale depends on the lens mass and angular-diameter distances. Here it is a normalized display control only.

    ⚑

    Scientific interpretation

    Real lens inference needs lens/source redshifts, a mass model, observational uncertainties, and validation against the image data.

    HOW TO READ IT

    From length scales to statistical summaries

    k

    Wave number k

    Higher wave number corresponds to smaller spatial scales under the common Fourier convention. Exact units depend on the chosen coordinate and normalization conventions.

    P

    Power P(k)

    A power spectrum summarizes fluctuation amplitude by scale. Estimator choices, window functions, shot noise, and units matter when analyzing real survey products.

    ≈

    Fit is not validation

    A curve that resembles an expected shape does not show that the simulator is physically correct or that an inferred posterior is calibrated.

    Ωm
    Matter density parameter

    Dimensionless matter density in the parameterization used by a model.

    σ₈
    Fluctuation normalization

    A conventional summary of matter fluctuation amplitude at a specified smoothing scale.

    h
    Scaled Hubble parameter

    Commonly defined through H₀ = 100 h km s⁻¹ Mpc⁻¹.

    nₛ
    Primordial spectral index

    Describes the tilt of the primordial scalar power spectrum in standard parameterizations.

    b
    Tracer bias coefficient

    A simplified mapping parameter between the matter field and a tracer field.

    SCIENTIFIC TRANSPARENCY

    About the visual lab

    νField Observatory is a frontend exploration layer for the νField Python starter. It provides explanatory visualizations plus import-only views of selected JSON metadata.

    Illustrations

    The expansion canvas, procedural cosmic web, and editable power spectrum are generated in the browser to demonstrate interaction and scientific UI conventions. They are not outputs from a calibrated cosmology solver.

    Imported artifacts

    Imported benchmark and dataset JSON values are displayed as provided, with source metadata and caution labels. The interface does not rerun inference or validate model assumptions.

    Privacy

    Files are read locally in the browser session. This static frontend contains no upload service and does not send file contents to a server.
